# ZaabOS — โปรแกรมขายหน้าร้าน (Windows / Mac)

ที่นี่มีเฉพาะ **ไฟล์ติดตั้ง** ของโปรแกรม ZaabOS · ดาวน์โหลดเวอร์ชันล่าสุดที่หน้า **Releases** (ด้านขวา)

- Mac: `ZaabOS-Local-macOS.zip`
- Windows: `ZaabOS-Local-Windows.zip`

## ติดตั้งบน Mac
1. ดาวน์โหลด `ZaabOS-Local-macOS.zip` แล้วดับเบิลคลิกเพื่อแตกไฟล์ จะได้ `ZaabOS.app`
2. ลาก `ZaabOS.app` ไปไว้ในโฟลเดอร์ **Applications**
3. เปิดครั้งแรก: **คลิกขวา → Open (เปิด)** แล้วกด **Open** อีกครั้ง
   - ถ้าขึ้นว่า "ไม่สามารถเปิดได้เพราะไม่ทราบผู้พัฒนา": ไปที่ **System Settings → Privacy & Security** เลื่อนลงล่าง กด **Open Anyway (เปิดต่อไป)**
4. หน้าขายเปิดเป็น **หน้าต่างโปรแกรม ZaabOS** (มีไอคอนใน Dock) และมีไอคอน ZaabOS ที่แถบเมนูด้านบนขวา
   - ปิดหน้าต่าง = ซ่อนเท่านั้น โปรแกรมยังทำงาน แท็บเล็ตและ QR ยังสั่งได้ · เปิดกลับจากไอคอนด้านบน → **เปิด ZaabOS**
   - ปิดโปรแกรมจริง: ไอคอนด้านบน → **ปิด ZaabOS**

## ติดตั้งบน Windows
1. ดาวน์โหลด **`ZaabOS-Setup.exe`** แล้วดับเบิลคลิก
2. ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC": กด **More info (ข้อมูลเพิ่มเติม)** → **Run anyway (เรียกใช้ต่อ)**
3. กด **Next** จนจบ → **Finish** — ZaabOS เปิดเอง มีไอคอนใน Start menu และบนหน้าจอ (Desktop)
4. หน้าขายเป็น **หน้าต่างโปรแกรม ZaabOS** และมีไอคอน ZaabOS ข้างนาฬิกามุมขวาล่าง
   - ปิดหน้าต่าง = โปรแกรมยังทำงาน แท็บเล็ตและ QR ยังสั่งได้ · เปิดกลับ: ดับเบิลคลิกไอคอน ZaabOS
   - ปิดโปรแกรมจริง: คลิกขวาไอคอนข้างนาฬิกา → **ปิด ZaabOS**
   - อัปเดต: ตั้งค่า → โปรแกรมในเครื่อง → **อัปเดต** (ไม่ต้องดาวน์โหลดใหม่)
   - ถอนการติดตั้ง: Settings → Apps → ZaabOS → Uninstall (ข้อมูลร้านยังอยู่ในเครื่อง)

ไม่มีอินเทอร์เน็ตที่เครื่องร้าน: ใช้ `ZaabOS-Local-Windows.zip` (แตกไฟล์ → เปิด `ZaabOS.exe`) ใส่ USB แบบ exFAT ไปแทนได้

> คำเตือนตอนติดตั้งเกิดจากโปรแกรมยังไม่ได้ลงทะเบียนลายเซ็นกับ Apple / Microsoft (มีค่าใช้จ่ายรายปี) — โปรแกรมปลอดภัย ใช้งานได้ตามปกติ

## เริ่มใช้งาน
1. เปิดครั้งแรกจะขึ้นหน้า **ตั้งค่าร้านครั้งแรก**: ชื่อร้าน · สกุลเงิน · ชื่อผู้ใช้และรหัสผ่านของเจ้าของ · รหัสพนักงาน (เช่น 999)
2. ใส่ **คีย์โปรแกรม** ที่ได้รับจาก ZaabOS: ตั้งค่า → ข้อมูลร้าน & ใบเสร็จ → โปรแกรมในเครื่องร้าน → **ใส่ / เปลี่ยนคีย์** (ครั้งแรกต้องต่ออินเทอร์เน็ต)
3. เพิ่มพนักงานพร้อมรหัสของแต่ละคนที่ ตั้งค่า → พนักงาน — ทุกคนเข้าหน้าขายด้วยรหัสสั้นๆ ของตัวเอง
4. ถ้ามีจอที่สองหันไปทางลูกค้า โปรแกรมจะเปิด **จอลูกค้า** ให้เอง

ข้อมูลการขายทั้งหมดเก็บอยู่ในเครื่องของร้านเท่านั้น · สำรองข้อมูลอัตโนมัติทุกวัน · อัปเดตจากเมนูในโปรแกรม
